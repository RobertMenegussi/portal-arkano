Pra atualizar uma build:
1. Coloque o ZIP novo dentro da pasta builds.
2. Abra index.html no bloco de notas / VS Code.
3. No const BUILDS, copie o primeiro bloco, cole acima dele e troque:
   build, version, date, title, file e notes.
4. Commit + push no GitHub.

A primeira build da lista é sempre a build atual.
As demais aparecem automaticamente no histórico.
